# SumCTriplan

כלי מקומי מבוסס `index.html` לבניית דוחות סיכום ודוחות מעמיקים מתוך נתוני לקוח ונתוני מסלקה.

## מה המערכת יודעת לעשות
- ייבוא נתוני מסלקה והצלבתם עם טופס לקוח
- זיהוי סוגי מוצרים פנסיוניים, נזילים והשתלמות
- חישובי נזילות, הלוואות, הפקדות, תחזיות פרישה וקצבה
- הפקת `דף סיכום` ו־`דוח מעמיק`
- הדפסה ל־PDF גם לרוחב וגם לאורך עם חלוקה לפי פרקים

## קובץ מרכזי
- `index.html` - האפליקציה כולה נמצאת כרגע בקובץ יחיד

## עבודה מקומית
1. פותחים את `index.html` בדפדפן
2. טוענים נתוני לקוח או מסלקה
3. מפיקים דוח סיכום או דוח מעמיק
4. שומרים כ־PDF לפי הצורך

## דגשים מקצועיים במערכת
- מוצר ללא תאריך נזילות תקין מוצג כ`לא נזיל`
- מוצר נזיל עם הלוואה מסומן כנזילות חלקית באמצעות צבע אזהרה
- חישוב הקצבה נשען רק על מוצרים פנסיוניים
- אם אין תחזית פרישה תקינה, מתבצע חישוב המשך צבירה לפי תשואה שנתית

## Git Hygiene
ה־repo מוגדר כך שלא ייכנסו אליו אוטומטית:
- קבצי מסלקה שחולצו
- קבצי PDF / ZIP / XLS
- קבצי גיבוי ו־swap
- קבצי עזר זמניים

## הערה
כיום הפרויקט בנוי סביב קובץ HTML יחיד. אם נרצה בהמשך לייצב ולתחזק אותו טוב יותר, השלב הנכון יהיה לפצל את הלוגיקה ל־CSS / JS / modules נפרדים.
